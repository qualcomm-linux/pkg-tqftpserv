# pkg-tqftpserv

Debian/Ubuntu packaging for the [tqftpserv](https://github.com/linux-msm/tqftpserv) project.
Upstream: https://github.com/linux-msm/tqftpserv

## Branches

- **qli-ci** (default): CI workflow stubs and repo metadata only. No upstream code.
- **upstream/latest**: Tracks upstream source (tag `upstream/1.1.1`).
- **qcom/ubuntu/resolute**: Ubuntu 26.04 LTS packaging, based on the Ubuntu resolute source package tqftpserv 1.1.1-1.

## Build

Go to the *Actions* tab → *Build* workflow → *Run workflow*, passing the desired `debian-ref`.
